# Good Practices para trabajar con prompts y contexto

Este documento recopila prácticas recomendadas para diseñar interacciones con modelos de IA de forma mantenible y escalable.

## Temas

1. Define objetivo, alcance y criterio de éxito antes de pedir salida.
2. Divide tareas complejas en pasos verificables.
3. Evita el "prompt spaghetti" con documentos de control.
